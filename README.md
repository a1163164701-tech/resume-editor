# 空白简历编辑器

一个可直接在浏览器中使用的中文简历编辑器。

## 功能

- 左侧填写，右侧实时预览
- 导入 PDF、DOCX、TXT 或 Markdown 简历并自动识别内容
- 按 PDF 坐标还原文字行与段落，并自动提取常见简历头像
- 导入前检查识别原文，可选择替换或合并现有内容
- 教育、工作、项目和技能模块
- 项目经历支持可选的开始月份和结束月份
- 自定义模块标题、全部字段名称与拖拽排序
- 技能模块标题与内容标签智能联动，也可分别修改
- 自定义字号、行距、间距、页边距和标题颜色
- 浏览器本地自动保存
- A4 PDF 导出

## 隐私

这是一个纯静态网站。用户填写的内容和上传的头像仅保存在用户自己的浏览器中，不会上传到服务器。
导入的简历文件也只在当前浏览器中解析。扫描图片型 PDF 没有可提取文字时，需要先转换为可复制文字的 PDF。
